Written by the session that executed `PKG-05b-decision-seam.md`. Read by every later package that depends on 05b. Keep every heading, even if the answer is "none".

## What changed

`services/decisions.py` is the typed decision seam (spec §13 A24): every closed question the loop asks a model goes through one typed function that takes a text-only State (no identifier fields, invariant 25) and returns a typed `Verdict` carrying its provenance (`Verdict.backend`), or `None` when no backend answered — the caller then records nothing, for either outcome. It has three live backends: `gemini` (the default), `function` (`SAPLING_MODEL_MODE=function`, the E2E lane) and `deterministic` (code). Jev is absent: a `jev` selection is served by Gemini with a `decision.fallback{jev_absent}` event, `shadow_jev` is a no-op, and `JEV_ENABLED` (default false; only `true` enables it) overrides every `DECISION_BACKEND_<NAME>` to Gemini. Grading delegates to PKG-05's `agents/grader.grade()` (one call, same prompt, same `llm_usage` rows); the other decisions run the new `agents/decision.py` agent (task `"decision"`, gemini-2.5-flash-lite, thinking off, one prompt, output type per run), which has a function-mode handler. `grade_answer` (PKG-05, reopened) now grades through `grade_rubric_items` / `reason_is_correct` and stamps the numeric clear-mismatch via `deterministic_yes_no("numeric_gate", False)`, with byte-identical grader messages. `decision.made` / `decision.shadow` / `decision.fallback` joined the event taxonomy; `tests/evals/decisions.py` measures the Gemini baseline on synthetic gold (dataset `decisions`, in `run_all.py`) and computes every §3.6 promotion gate; ADR 0027 amends ADR 0024. Flag-dark: nothing outside `agents/tools/check.py` imports the seam, no route calls `grade_answer` before PKG-07, and `main` does not even import `services.decisions`, so the product is byte-identical with `LEARNING_LOOP_ENABLED` unset, false or true.
