# HANDOFF-06 — zpd-policy

Written by the session that executed `PKG-06-zpd-policy.md`. Read by every later package that depends on 06. Keep every heading, even if the answer is "none".

## What changed

The ZPD policy layer exists as pure code under `backend/learning/`: the hint ladder with the template check pose and the deterministic H2/H4/H6 payloads (`ladder.py`), the ceiling / evidence-by-rung / band-control / wheel-spin policy plus the tutor tier router (`model_tier`, spec §3.5 `LOOP_MODEL_TIER`, A15) and the per-phase context and tool policy (`context_policy`, A18) (`policy.py`), the attempt / rung-dwell / H6 / offer gates with an injectable clock and A5's gate time scale (`gates.py`), and a deterministic answer-leak detector and one-pass stripper (`leak.py`). `sessions.loop_state jsonb NOT NULL DEFAULT '{}'` exists (migration `20260927093843_learning_session_loop_state.sql`) and round-trips through `learning/loop_state_store.py`, which updates by session id, reports a lazy (missing) row as `False`, and never inserts or upserts a `sessions` row (A11); the typed `LoopState` carries every key it does not own through a load/save untouched. The six `zpd.*` event types are in `EVENT_TAXONOMY` and `learning/zpd_events.py` emits them through keyword-only helpers (`zpd.step` carries `tier` and `grader_backend` only when known). Invariants 4 and 5 are asserted and invariant 2 is extended for `ladder.deterministic_content`. Nothing outside `learning/` and `tests/` imports any of it (an ast test proves it, and a second test imports the real app in a clean interpreter and finds no PKG-06 module in `sys.modules`), so flag-off behaviour is byte-identical: the only runtime-visible changes are six extra taxonomy strings and one defaulted jsonb column. PKG-07 wires the loop tutor through it.

- `::LoopState` — dataclass `steps: dict[str, StepState]`, `current: str | None`, `checks_since_rating: int`, `extra: dict` (every top-level key PKG-06 does not own); `rating_due()` (`checks_since_rating ≥ ZPD_RATING_EVERY_N_CHECKS`), `to_json() -> dict` (`{"v", "current", "checks_since_rating", "steps": {qh: {"rung", "attempts", "first_shown_at", "last_rung_at", "attempted_at", "showed_work", "exam_mode"}}}` plus the extras; deep copies), `LoopState.from_json(data) -> LoopState` (`{}` → fresh; `ValueError` on a non-object document, a non-object `steps` or step, a step without a finite numeric `first_shown_at`, an off-ladder rung, a negative or non-int count, a non-bool flag, a non-numeric `last_rung_at`/`attempted_at`, a non-string `current`), `LoopState.recover(data) -> LoopState` (never raises: each malformed PKG-06 unit starts fresh on its own — a step that fails validation restarts with its PKG-06 fields at their defaults (a finite `first_shown_at` kept) and keeps its foreign keys in `StepState.extra`; a non-object step, or every step when `steps` is not an object, is dropped and a `current` naming it is cleared; a bad `current`/`checks_since_rating` takes its default — and every top-level foreign key survives in `extra`; a non-object document → fresh). - `backend/learning/gates.py::NON_ATTEMPT_PATTERNS` — exactly `("just tell me", "give me the answer", "idk", "i don't know", "what's the answer")`.
- `::non_attempt_phrases(text) -> tuple[str, ...]` — the `NON_ATTEMPT_PATTERNS` (in their order) that make the MESSAGE a non-attempt, `()` when it is not one. Phrases match whole (lowercase, apostrophes (`'’‘ʼ`´`) deleted, other non-alphanumerics → space). A phrase makes the message a non-attempt only when nothing else in it is an answer: set aside the phrases, a REQUEST phrase's object (the rest of its clause after "just tell me" / "give me the answer" / "what's the answer": "just tell me the steps", "what's the answer to part 2"; clauses split at sentence/clause punctuation — a `.` or `,` between digits is part of a number — brackets, newlines, `but`), the pleas `_PLEA` ("no idea"/"no clue", "give up", "too/so/really/very/… hard", "this is hard") and the non-answer words `_NON_ANSWER` (filler, function words, help/stuck/give-up vocabulary: "where do I start", "can you give me a hint", "I've been trying for ages"); any word left — a number or a content word, before or after an idk phrase, with or without punctuation between — or a relation symbol (`= < > ≈ ≠ ≤ ≥`) anywhere is an answer. `yes`/`no`/`true`/`false`/`up`/`hard`/`right` are answers. So "x = 7. idk if the units are right", "idk maybe 7", "42 idk" and "the mitochondria idk" are `()` and get graded; "idk, what do I do?", "Just tell me. This is too hard" and "I give up. What's the answer?" are non-attempts.
- `::matches_non_attempt(text) -> bool` — `bool(non_attempt_phrases(text))`. These two are the only functions in the layer that read text.
- `::is_genuine_attempt(text_len_chars, has_shown_work, matched_non_attempt, independent_seconds, band, *, time_scale=1.0) -> bool` — False when matched (a non-attempt message vetoes a filled work field too; a hedged answer never matches; a plea beside a phrase always does, so it never unlocks a rung or counts toward H6), when there is neither text nor shown work, or when `independent_seconds < gate_seconds(GATE_INDEPENDENT_MIN_S[_NOVICE], time_scale)`; `ValueError` on an unknown band or NaN seconds.
- `::rung_unlock(step: StepState, now: float, *, time_scale=1.0) -> bool` — `now − anchor ≥ gate_seconds("GATE_RUNG_DWELL_MIN_S", time_scale)` AND some `attempted_at > anchor`; anchor = `last_rung_at`, else `first_shown_at`. Returns a bool, not `(ok, reason)`.
- `::h6_allowed(step, *, item_taught: bool, item_practice: bool, item_graded: bool) -> bool` — A32; the three predicates are keyword-only.
- `::offer_allowed(band, last_attempt_wrong) -> bool` — `band in OFFER_BANDS and last_attempt_wrong`.
- `backend/learning/params.py::gate_seconds(name: str, scale: float = 1.0) -> float` — a numeric module-level `GATE_*` constant × `scale` (A5); `ValueError` for any other name and for a scale that is not finite and > 0. New `GATE_*` names (e.g. PKG-14's `GATE_INDEPENDENT_MIN_S_VARIANT_B`) are accepted automatically.
- `backend/learning/leak.py::LeakVerdict(leaked: bool, detector: Detector)`, `::Detector = Literal["none", "ngram", "final_answer"]`, `::WITHHELD = "[withheld]"`.
- `::tokens(text) -> list[str]` — ASCII alphanumeric runs, lowercased.
- `::final_answer(reference) -> tuple[str, ...]` — the tokens of the clause after the LAST `=` (the clause ends at `,` (not a thousands separator: "= 1,250 J" → `1 250 j`) `;` newline, a whole-word `and`/`so` in any case, or `.`/`!`/`?` not followed by a digit); an empty clause or no `=` → the tokens of the last standalone number (thousands-separated numbers whole) that is not a line-leading numbered-step label (`^[ \t]*(?:step[ \t]*)?\d+[.):]` case-insensitive, not followed by a digit, followed by text: a stepwise reference's "2." / "2)", "Step 2:" and "1.Convert" are no answer; a line "42.", a decimal "1.5 m" and a clock time "12:30" are); `()` when neither.
- `::detect_leak(reference_answer, emitted, rung) -> LeakVerdict` — rung ≥ H6 → `(False, "none")`; any shared n-gram with n = `min(LEAK_NGRAM, reference token count)` → `"ngram"` (a reference shorter than `LEAK_NGRAM` tokens leaks when its whole token run appears, as PKG-04's `leak_in_prompt` compares); the final-answer run as consecutive tokens, or the same run with every ASCII number compared by value ("1,250" = "1250" = "01,250.0", "2.50" = "2.5") → `"final_answer"`. `strip_leak` uses the same n and the same by-value rule.
- `::strip_leak(emitted, reference) -> str` — one pass: every maximal run of tokens covered by a leaked n-gram or the final-answer run (plain or by value) becomes ONE `WITHHELD`, a number touched by a run is withheld whole ("1,250" never becomes "1,[withheld]"), text between runs untouched, existing markers never re-matched; the result passes `detect_leak(reference, ·, H0)` (unless the reference itself contains the word "withheld") and a second call is a no-op (1,000-case property test).
- `backend/learning/loop_state_store.py::load_loop_state(session_id) -> LoopState` — `table("sessions").select("loop_state", filters={"id": "eq.<id>"}, limit=1)`; no row → fresh; a malformed document → `LoopState.recover(doc)` + WARNING (malformed PKG-06 fields fresh, every other package's key kept); a read ERROR propagates (a fresh answer would let the next save overwrite the real state; Deviations).
- `::save_loop_state(session_id, state) -> bool` — `table("sessions").update({"loop_state": state.to_json()}, filters={"id": "eq.<id>"})`; no row matched → `False` + WARNING (`not materialised`); never `.insert(`/`.upsert(` (A11, pinned by source scan). Keys on the session id only: the caller checks ownership. Replaces the whole document, last writer wins (Known gaps).
- `backend/learning/zpd_events.py::emit_zpd_step`, `emit_zpd_offer`, `emit_zpd_band_adjust`, `emit_zpd_wheelspin`, `emit_zpd_leak`, `emit_zpd_rating` — every parameter keyword-only; payload keys exactly spec §6 (`zpd.leak` carries `request_id` in the payload too); rungs as ints, enums as their `.value`; `emit_zpd_step(..., tier: Tier | None = None, grader_backend: GraderBackend | None = None)` puts each key in the payload only when not `None`. A payload that cannot be built (a caller bug, e.g. a `rungs` entry without `dwell_ms`), or that holds a string longer than `params.EVENT_PAYLOAD_STR_MAX` (64) or a value that is not None/bool/int/float/str/list/string-keyed dict, is dropped with a WARNING, never raised; the payload's `request_id` (zpd.leak) is exempt from the length cap, since it is the events row's own `request_id` column value too (request_context accepts 8..128 chars). `emit_zpd_step(channel: learning.evidence.Channel)`.
