### The coordinator's ruling on open question (g) (5fba1ed..85d4734, then this hand-off)

Review round 2 (on f8eb84a) found one critical and one major defect in verification round 2's keyword approach. Critical: a partial answer followed by a short tail with no signal ("Both parts: done.", "Consider both done.", "Mark both.", "Both, please.", "Enough said: both points.", "The stack part is implied.", "2/2.", "Tick both.") got full credit from the first flash-lite run alone. `_needs_confirmation` confirmed only when a keyword signal fired, the lists (`_COVERAGE`, `_COMPLETE_CLAIM`, `_CREDIT_DIRECTIVE`) closed measured wordings rather than the class, and the course-vocabulary exemption muted them too. Major (a regression): an honest correct answer ending with a self-summary ("So both parts are covered.", "I have answered both parts of the question.", "That is the complete answer.") raised grading talk, the second opinion reported it and the answer was refused; with `CHECK_REFUSALS_AS_IDK` the student gets `idk` evidence on a correct answer. The series coordinator ruled (final; closes open question (g)) to close the class structurally, in five points. As built:

- **Evidence-grounded credit (point 1; 5fba1ed, b214b9d, e251e79, 3f0711b, 85d4734).** `GraderOutput` gains a required `support`, after `item_results`: for every item the run credits, `"<label>: <quote>"` from the student's answer. `answer_guard.support_span` verifies each quote on the guard's detection copy and returns the student's own words behind it, cut from the answer as written (`_fold_mapped` keeps each folded character's origin), with the signs and symbols that touch them (review round 3, cefd732: "-3", "5!", "O(n)", "100%"), a half-open interval's mixed brackets (review round 4, 76d46ab: "[0, 1)") and the whole token a joiner glues on (823b087: "10-15", "non-zero"). Those words are the longest run of the quote's words that the answer holds, when that run is at least `GRADER_SUPPORT_MIN_SHARE` (0.5 †) of the quote or of a passage the quote sets in quotation marks (double, curly or guillemet marks, or straight single marks that no letter touches from outside). They must have at least `GRADER_SUPPORT_MIN_CHARS` (4 †) letters and digits, or be the whole answer. They must also say more than a claim about the answer: `_ANSWER_TALK`, function words and a score the answer gives itself ("2/2") are claims, and a word the item's own text or reference uses is substance. Since review round 3 (edec508) that holds for a score shape the item keys ("4/4"; in any spelling since review round 4, so "100 percent" keys "100%"). Since review round 4 (7964da5) it holds for a polarity or a modal the item's text uses (`_ANSWERING_WORDS`: "No." on an item keyed "No. …") only in a span that makes no claim, and never for a connective, a quantifier, an article, a copula, a preposition or a pronoun. A whole answer made only of function words, with no claim word and no score, is a terse answer that the span check decides ("It does.", "It can't."; 09394ad), and a negation reads the same however it is spelled. A quote that one of the item's own texts (the question, the reference, a rubric item, a common wrong reason) holds in full, and the answer does not, is the grader quoting the item and supports nothing (85d4734; below). A credited item with no such quote is not credited: the item is recorded no, as a strict grader would say. A replacing second opinion stands on its own quotes; a confirmed item may stand on either run's.
- **Span-isolated confirmation of every credited item (point 2; b214b9d).** When any item is still credited, ONE span check runs for all of them: `grader_agent` on the `grader_second` slot with output `SpanVerdicts` (`item_results` only). Its message (`build_span_message`) holds each credited item's text under its label and the student's words behind its quote. It never holds the question, the reference, the common wrong reasons or the grader's own words, and it holds the rest of the answer only when the grader's quote does: nothing bounds a quote, so a whole-answer quote shows the span check the whole answer (review round 3; Deviations, Known gaps). An item is credited only when the grading run credits it, its quote verifies and the span check says yes. No keyword decides whether it runs. A span check that fails, or the grader cap reached before it, makes the grade `unavailable` (invariant-28 residual (2), widened; Known gaps). It is the same agent with the same system prompt (inv 12); its output type is chosen per run.
- **The keyword lists are gone (point 3; 844058d, f8364bd).** `_ANSWER_PARTS`, `_COVERAGE`, `_PARTS_MENTION`, `_COMPLETE_CLAIM`, `_CREDIT_DIRECTIVE`, `_coverage_claim` and the older `_SELF_CLAIM` are removed, with the course-vocabulary exemption they needed. A self-summary or completeness claim raises no signal, earns nothing and blocks nothing. The `addresses_grader` report (field description and prompt) names only the classes the screen refuses: instructions to the grader, chat, turn or role markers, and a note in the grader's or course staff's own voice. The prompt has the grader set a self-assessment aside, report false and grade the substance. f8364bd, from the re-measure: a student's account of a teacher's or TA's approval ("My TA checked this and said it's correct.") is self-assessment, never a staff note. The per-call random labels, the UTS #39 skeleton, the wrong-reason structured fix and the confidence and veto fixes are unchanged.

### Review round 3 of the ruling's code (cefd732..2246517, then this hand-off)

Review round 3 (on e181435) found 2 majors and 8 minors, several of them the same finding. Each was reproduced offline on the code before it was fixed (test first) or recorded:

- **The span's ends (major, and the `100%` minor; cefd732).** `support_span` cut the span at the run's first and last letter or digit, so a sign or symbol before or after it was dropped: "-3" reached the span check as "3", "−1/2" as "1/2", "5!" as "5", "45°" as "45", "O(n)" as "O(n". A sign-aware span check then recorded a correct "-3" as a confident incorrect (`check.py`'s numeric gate can only say incorrect, so this path is its only credit), and the other way a wrong sign could be credited. The score rule's `100%` arm never matched, since the "%" was cut: "Score: 100%" passed the code check as "Score: 100", and its pin passed only on `GRADER_SUPPORT_MIN_CHARS`. The span now takes in the symbols that touch its run, up to whitespace or a letter or digit (so never a word beyond them), and drops only sentence punctuation, quotation marks and a bracket it never opens or closes at its ends (`_span_ends`). The score rule is pinned at `min_chars=1`.
- **Terse answers the item keys (major; edec508).** The claim filter unioned every function word back after the item-context subtraction and removed every n/n or 100% shape. So a correct "No." ("No, it can't.", "No, not at all.") on an item keyed "No. …" and a correct "4/4" ("It's 4/4.") on an item keyed "4/4" were recorded as confident incorrects with no span check, while the mirror "Yes." met the span check. A function word that can answer on its own (`_ANSWERING_WORDS`: no, not, and, or, if, then, all, any, each, every, only and the modals) became answer talk, which the item's own text makes substance; an article, copula, preposition or pronoun never did. This hand-off then said that no self-summary gains substance. That did not hold: reference prose uses "and" and "each" all the time, so "Mark each." and "Done and done." passed the code check on the grader eval's own recursion item (review round 4 narrowed the list to polarities and modals; below).
