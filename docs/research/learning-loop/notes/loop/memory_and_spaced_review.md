# Cognitive science of durable learning for an AI tutor's per-concept review loop

Scope: forgetting models and scheduling algorithms (SM-2, FSRS-4.5/5/6, Duolingo HLR, ACT-R, DASH), the testing and spacing effects, interleaving, desirable difficulties, successive relearning, cognitive-load limits, and how to turn all of it into a per-concept scheduler for a semester-long college course with a per-course knowledge graph.

Source-quality legend used throughout: **[lab, word pairs/lists]**, **[lab, prose/concepts]**, **[classroom]**, **[production app data]**, **[algorithm author docs]**.

## Key Question 1: Exact FSRS equations, default parameters, how FSRS differs from SM-2, and the recommended retention target (plus SM-2, HLR, ACT-R, Ebbinghaus reference forms)

### Takeaway
FSRS models each item as a triple (Difficulty D in [1,10], Stability S in days, Retrievability R in [0,1]) with a power-law forgetting curve and closed-form updates; the interval is solved directly from a *desired retention* r, which the authors bound to 0.70–0.97 and default to 0.90 ("90% should work fine for most people"), with a simulator-based "minimum recommended retention" that minimizes workload/knowledge (typically landing near 0.85). SM-2 has no memory model at all — it multiplies the last interval by a per-item ease factor — so it cannot express a retention target, cannot handle late/early reviews, and in benchmarks FSRS-6 beats it on log-loss for 99.6% of users with ~20–30% fewer reviews at equal retention.

### Cited Findings

**FSRS core definitions [algorithm author docs]**
- Retrievability R = "probability that the person can successfully recall a particular piece of information at a given moment"; Stability S = "the time, in days, required for R to decrease from 100% to 90%"; Difficulty D "affects how fast stability (and hence intervals) grows after each review". — [ABC of FSRS wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/ABC-of-FSRS)
- FSRS-4.5 forgetting curve: `R(t,S) = (1 + FACTOR · t/S)^DECAY`, with `DECAY = -0.5`, `FACTOR = 19/81`, chosen so that `R(S,S) = 0.9`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- FSRS-6 forgetting curve makes the decay a trainable parameter: `R(t,S) = (1 + factor · t/S)^(-w20)` where `factor = 0.9^(-1/w20) - 1`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Interval from desired retention r: `I(r,S) = (S/FACTOR) · (r^(1/DECAY) - 1)`, constrained so `I(0.9,S) = S`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Initial stability after the first rating G (1=Again, 2=Hard, 3=Good, 4=Easy): `S0(G) = w[G-1]` (a lookup, w0..w3). — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Initial difficulty: FSRS-4/4.5: `D0(G) = w4 - (G-3)·w5`; FSRS-5/6: `D0(G) = w4 - e^(w5·(G-1)) + 1`; D clamped to [1,10]. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Difficulty update (FSRS-5/6, "linear damping" + mean reversion): `ΔD(G) = -w6·(G-3)`; `D' = D + ΔD·(10-D)/9`; `D'' = w7·D0(4) + (1-w7)·D'`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Stability after successful recall: `S'_r(D,S,R,G) = S · ( e^(w8) · (11-D) · S^(-w9) · (e^(w10·(1-R)) - 1) · w15[if G=2] · w16[if G=4] + 1 )`. The factor `(e^(w10·(1-R)) - 1)` is the built-in spacing effect: "The smaller the value of R, the larger the SInc value. This means that the spacing effect accumulates over time." `(11-D)` makes harder items grow slower; `S^(-w9)` gives diminishing stability growth for already-stable items. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Stability after a lapse (Again): `S'_f(D,S,R) = w11 · D^(-w12) · ((S+1)^(w13) - 1) · e^(w14·(1-R))`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Same-day (short-term) review, FSRS-6: `S'(S,G) = S · e^(w17·(G-3+w18)) · S^(-w19)`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Default parameters, FSRS-6 (21 params, w0..w20): `[0.212, 1.2931, 2.3065, 8.2956, 6.4133, 0.8334, 3.0194, 0.001, 1.8722, 0.1666, 0.796, 1.4835, 0.0614, 0.2629, 1.6483, 0.6014, 1.8729, 0.5425, 0.0912, 0.0658, 0.1542]`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Default parameters, FSRS-5 (19 params): `[0.40255, 1.18385, 3.173, 15.69105, 7.1949, 0.5345, 1.4604, 0.0046, 1.54575, 0.1192, 1.01925, 1.9395, 0.11, 0.29605, 2.2698, 0.2315, 2.9898, 0.51655, 0.6621]`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Default parameters, FSRS-4.5 (17 params): `[0.4872, 1.4003, 3.7145, 13.8206, 5.1618, 1.2298, 0.8975, 0.031, 1.6474, 0.1367, 1.0461, 2.1072, 0.0793, 0.3246, 1.587, 0.2272, 2.8755]`. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Note the FSRS-6 defaults imply a first-Good item starts at S0 = w2 = 2.31 days and a first-Easy item at w3 = 8.30 days; with w20 = 0.1542 the FSRS-6 curve is much flatter-tailed than the -0.5 power of FSRS-4.5 (i.e., slow initial drop, long tail). — arithmetic on the defaults above, [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)

**Retention target [algorithm author docs]**
- Desired-retention permissible range is 0.70–0.97 (0.70–0.99 in Anki 23.10.1+); "80–95% is reasonable" and "90% should work fine for most people"; above 0.97 "significantly increase[s] your workload" and turns spaced repetition into massed repetition. — [fsrs4anki tutorial](https://github.com/open-spaced-repetition/fsrs4anki/blob/main/docs/tutorial.md)
- "Higher retention leads to more reviews per day"; users should tune desired retention rather than parameters. — [ABC of FSRS wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/ABC-of-FSRS)
- Workload vs. retention is U-shaped: higher retention → shorter intervals → more reviews; lower retention → more lapses → more relearning. The optimizer (Anki 24.04+) searches the retention that minimizes `workload / knowledge` where knowledge = sum of recall probabilities over all cards, via long-run simulation + Brent's method. The authors explicitly prefer minimizing workload/knowledge over minimizing absolute workload. — [The optimal retention wiki](https://github.com/open-spaced-repetition/fsrs4anki/wiki/The-optimal-retention)
- "Compute minimum recommended retention" (CMRR): simulate N days (12 months suggested for exam prep, 5 years for language) and return the retention giving the most efficient plan; "you shouldn't set retention below the recommended value" but may set it higher. — [fsrs4anki tutorial](https://github.com/open-spaced-repetition/fsrs4anki/blob/main/docs/tutorial.md)
- Secondary summaries of the FSRS docs report the CMRR "optimal retention is around 85%" for typical users, with 0.70–0.97 allowed. — [search summary of FSRS docs / Anki forums](https://forums.ankiweb.net/t/about-minimum-recommended-retention-cmrr/54501) (not primary; treat as indicative)

**FSRS vs SM-2 [algorithm author docs / benchmark]**
- FSRS needs "20–30% fewer reviews than with SM-2 algorithm to achieve the same retention level" (2026 simulation) and "handles delayed reviews significantly better". — [ABC of FSRS wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/ABC-of-FSRS)
- Benchmark over 500M+ reviews: FSRS-6 log loss 0.3460 vs FSRS-5 0.3560; FSRS-6 (recency-weighted, per-user optimized) has lower log loss than Anki-SM-2 for 99.6% of users; caveat: SM-2 "was never designed to predict probabilities", so the comparison bolts a retrievability formula onto it. — [srs-benchmark](https://github.com/open-spaced-repetition/srs-benchmark), [Benchmark of SR algorithms](https://expertium.github.io/Benchmark.html)

**SM-2 (1987) reference form [algorithm author docs]**
- Intervals: `I(1) = 1 day`, `I(2) = 6 days`, `I(n) = I(n-1) · EF` for n > 2. Every item starts at `EF = 2.5`; `EF` floor is 1.3. After each response with quality q in 0..5: `EF' = EF + (0.1 - (5-q)·(0.08 + (5-q)·0.02))`; q = 4 leaves EF unchanged; q < 3 restarts the repetition count (interval back to I(1)) without changing EF. — [SuperMemo SM-2 algorithm page](https://www.super-memory.com/english/ol/sm2.htm)

**Duolingo half-life regression (Settles & Meeder 2016) [production app data]**
- Forgetting curve: `p = 2^(-Δ/h)` (Δ = days since last practice, h = half-life in days); half-life regression `h_Θ = 2^(Θ·x)`; loss `ℓ = (p - 2^(-Δ/h_Θ))^2 + α·(h - h_Θ)^2 + λ‖Θ‖²` where the algebraic target is `h = -Δ / log2(p)`. — [Duolingo blog](https://blog.duolingo.com/how-we-learn-how-you-learn/), [ACL 2016 paper PDF](https://aclanthology.org/P16-1174.pdf)
- Features x: per-word interaction counters — total exposures x_n, correct recalls x_⊕, incorrect x_⊖ (square roots of the counts worked better than raw counts) — plus sparse lexeme-tag indicators and a bias. — [ACL 2016 paper PDF](https://aclanthology.org/P16-1174.pdf), [halflife-regression README](https://github.com/duolingo/halflife-regression)
- Evaluation on 12.9M student-word session traces (90/10 split): HLR MAE 0.128, AUC 0.538, half-life Spearman 0.201; Leitner MAE 0.235; Pimsleur 0.445; logistic regression 0.211; constant-prediction baseline (p̄ = 0.859) MAE 0.175 — i.e., only the HLR variants beat predicting the mean. — [ACL 2016 paper PDF, Table 2](https://aclanthology.org/P16-1174.pdf)
- Live A/B: +9.5% retention in practice sessions, +1.7% lessons, +12% overall activity; error reduced 45%+ vs baselines. — [Duolingo blog](https://blog.duolingo.com/how-we-learn-how-you-learn/), [ACL 2016 paper PDF](https://aclanthology.org/P16-1174.pdf)
- Caveat: AUC of 0.538 is barely above chance; HLR's win is mostly calibration (MAE), not ranking. — [ACL 2016 paper PDF, Table 2](https://aclanthology.org/P16-1174.pdf)

**ACT-R (Pavlik & Anderson 2005) [lab, word pairs]**
- Each practice adds a strength trace that decays as a power of time; the decay rate of each trace depends on activation at the time of that practice ("decay for a trial is based on the current activation at the time of that trial, rather than a set decay rate"), which "limits long-term benefits from further practice at higher levels of activation and produces the spacing effect". Japanese–English vocabulary experiment: "the relative benefit of spacing increased with increased practice and with longer retention intervals." — [Pavlik & Anderson 2005, PubMed](https://pubmed.ncbi.nlm.nih.gov/21702785/), [Semantic Scholar](https://www.semanticscholar.org/paper/623c8cf67b4347007184887b524c29176b55a1d4)
- Standard written form (as reported in the ACT-R literature; not re-verified verbatim in this session — see Gaps): base-level activation `m_n = β + ln( Σ_{k=1..n} t_k^(-d_k) )`, with `d_k = c·e^(m_{k-1}) + a`, and recall probability `P = 1 / (1 + e^((τ - m)/s))`. — [Pavlik & Anderson 2005 (ResearchGate listing)](https://www.researchgate.net/publication/51247506_Practice_and_Forgetting_Effects_on_Vocabulary_Memory_An_Activation-Based_Model_of_the_Spacing_Effect)

### Inferences
- For a per-concept scheduler, adopt the FSRS state triple (D, S, R) and the FSRS-6 update equations as the base memory model, but treat the 21 default parameters as *priors* only: they were fit on Anki flashcard data (short cloze/QA cards, self-graded 4-button responses). Concept-level checks graded by an LLM are a different response distribution; expect to refit w0..w3 (initial stability) and w8..w10 (growth) once you have a few thousand concept reviews.
- Choose the retention target per course phase: 0.90 default (authors' recommendation), dropping to ~0.85 for large concept sets where CMRR-style simulation shows the workload/knowledge optimum, and raising toward 0.95 only in the 1–2 weeks before an exam (this is exactly the "cram" regime the docs warn about, but it is intentional there).
- HLR's log-linear form (`h = 2^(Θ·x)`) is the easiest to implement when you have heterogeneous evidence: every check type becomes a feature and the fit is a plain regression. FSRS gives better calibration per review but assumes a 4-level rating; HLR/DASH assume binary correctness with counts. A hybrid — FSRS state updates with the rating derived from check outcome + check difficulty — is the pragmatic middle path (see Q2).
- SM-2 should not be the production scheduler: no notion of retrievability, so it cannot compute "what is this student most likely to have forgotten right now", which is the query a tutor needs.

### Gaps
- The ACT-R equations above are given in their standard textbook form; the session could not fetch the full Pavlik & Anderson 2005 PDF to quote the exact symbols and the fitted constants (c, a, τ, s). Verify before implementing.
- No primary source retrieved for the Ebbinghaus 1885 curve or its 2015 replication (Murre & Dros); the modern consensus that forgetting is closer to a power law than an exponential is reflected in FSRS's power-form R(t,S) and in ACT-R's power decay, but the Ebbinghaus data themselves were not reviewed here.
- The "~85% optimal retention" figure is from community summaries of the CMRR feature, not a paper; the primary docs only state 0.70–0.97 permitted, 0.90 default, and the workload/knowledge objective.
- Anki's SM-2 variant (ease 250%, hard/easy multipliers, interval modifier) was not sourced; only canonical SM-2 is documented here.

## Key Question 2: Scheduling *concepts* (not flashcards) when evidence comes from varied checks (MCQ, free response, teach-back), and how check difficulty affects stability gain

### Takeaway
The research supports two rules: (a) more effortful, successful retrieval (free recall/short answer > recognition/MCQ; lower retrievability at time of test) produces larger memory gains — but only when the retrieval succeeds and feedback follows; (b) a per-concept "knowledge component" model (DASH/DAS3H) with time-windowed correct/attempt counts is the published way to aggregate heterogeneous evidence, and it reaches classroom effect sizes of d ≈ 1.4 vs massed study. No published scheduler directly maps MCQ vs teach-back onto FSRS stability; that mapping must be engineered and then fit.

### Cited Findings
- Retrieval effort hypothesis: with retrieval success held constant, harder retrievals (longer interstimulus intervals, higher criterion) produced higher final test performance — "as the difficulty of retrieval during practice increased, final test performance increased." **[lab, word pairs (Swahili–English)]** — [Pyc & Rawson 2009, ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S0749596X09000138)
- FSRS encodes exactly this: the stability increment term `(e^(w10·(1-R)) - 1)` grows as R at review time falls, so a successful recall at R = 0.7 yields a larger S jump than one at R = 0.95. — [The Algorithm wiki](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
- Test format: Kang, McDermott & Roediger 2007 (college students, short journal articles, final test 3 days later) **[lab, prose/concepts]** — without feedback, MC quizzes beat short-answer (because initial SA success was much lower); with corrective feedback, short-answer practice produced the largest gains and beat MC practice on an MC final test (d = 0.41). — [Kang et al. 2007 summary](https://notes.andymatuschak.org/zTxLkeaWCdBHQYW73o5n6Ka), [WashU listing](https://profiles.wustl.edu/en/publications/test-format-and-corrective-feedback-modify-the-effect-of-testing-/)
- Meta-analyses disagree on format: Rowland 2014 (lab-only) found short-answer/recall > MC; Adesope et al. 2017 (includes applied studies) found MC > short answer and a format-match bonus (practice format = criterion format). Both agree feedback and initial-retrieval success reliably raise the effect. — [Frontiers 2018 review of both](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2018.02412/full), [Rowland 2014, PubMed](https://pubmed.ncbi.nlm.nih.gov/25150680/), [Adesope et al. 2017](https://journals.sagepub.com/doi/abs/10.3102/0034654316689306)
- Classroom quizzing meta-analysis (Yang et al. 2021, 222 studies, 48,478 students): overall g = 0.499; with corrective feedback g = 0.537 vs g = 0.374 without; more quiz repetitions → larger effect. **[classroom]** — [Yang et al. 2021, PubMed](https://pubmed.ncbi.nlm.nih.gov/33683913/)
- Retrieval practice on educational science texts (Karpicke & Blunt 2011, college students, 1-week delay) beat elaborative concept mapping on verbatim *and* inference questions and even on a final concept-map test; students predicted the opposite. **[lab, prose/concepts]** — [Karpicke & Blunt 2011, Science](https://www.science.org/doi/10.1126/science.1199327), [PubMed](https://pubmed.ncbi.nlm.nih.gov/21252317/)
- DASH (Lindsey et al. 2014) recall model for knowledge component i, student s: `Pr(R_si = 1) = logistic[ D_s - G_i + Σ_w ( φ_w·log(1 + c_siw) - ψ_w·log(1 + n_siw) ) ]`, where c_siw = correct recalls of KC i in time window w, n_siw = attempts in window w, φ_w/ψ_w = window weights (windows span increasing timescales; add-one smoothing); the difference of log terms yields a power law of practice. **[classroom]** — [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)
- Review-selection policy used with DASH: prioritize the item whose predicted recall probability is closest to a threshold T; simulations (Khajah et al. 2013, against MCM and ACT-R student models, 10-week course, fixed weekly review budget) found T = 0.33 best and "only slightly" worse than the intractable optimal policy; the authors tie this to Bjork's "restudy when on the verge of being forgotten." — [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)
- DAS3H (Choffin et al. 2019) extends DASH to items that involve *multiple* knowledge components: per-KC learning and forgetting curves from interaction timestamps and outcomes; outperformed four state-of-the-art student models on three large datasets. — [DAS3H, EDM 2019 (arXiv)](https://arxiv.org/pdf/1905.06873), [ERIC](https://files.eric.ed.gov/fulltext/ED599174.pdf)
- In Lindsey et al. 2014 the review items were typed-translation retrieval trials (a single check type); items per student per condition averaged 7.6 study-to-proficiency trials + 8.0 review trials over the semester, with mean days between review trials of 0.12 (massed), 1.69 (generic spaced), 4.70 (personalized). — [Lindsey et al. 2014 PDF, Table 1](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)

### Inferences
- Map each check outcome to an FSRS rating with a difficulty-aware rule rather than a flat correct/incorrect: e.g., teach-back / free-response explained correctly → Good or Easy (weight `w16` easy bonus only if fluent and unprompted); MCQ correct → Good but with a *capped* stability multiplier (recognition is weaker evidence than recall; Kang 2007 and Rowland 2014); MCQ correct after a hint, or partially correct free response → Hard (`w15` penalty); wrong → Again. Store the check type and the pre-check R on every review row so w8..w10 and any per-check-type multiplier can be refit from data later.
- Retrieval effort research implies the scheduler should *prefer* harder check types when predicted R is already high (an MCQ at R = 0.95 is near-worthless evidence and near-worthless learning), and easier/scaffolded checks when R is low, so that retrieval still *succeeds* (the effect disappears on failed retrieval without feedback).
- Always attach corrective feedback to a check; the effect size roughly halves without it (g 0.537 → 0.374).
- For a knowledge graph, use DAS3H's framing: a single quiz item touches several concept nodes; credit/discredit each touched node's counts. This is how "one free-response question about gradient descent" updates both `gradient` and `learning rate` nodes.
- Prefer the DASH "closest-to-threshold" selection (T ≈ 0.33 in simulation; note that is a *recall probability* threshold well below FSRS's 0.9 desired retention, because it optimized long-term retention under a fixed review budget rather than minimizing lapses) as the tie-breaker when the daily budget is smaller than the FSRS due list. A blend — "due by FSRS, ordered by |R - T|" — is defensible.

### Gaps
- No peer-reviewed source found that quantifies stability gain as a function of check type (MCQ vs free response vs teach-back) inside a spaced-repetition model; the FSRS `w15`/`w16` multipliers are for self-rated Hard/Easy, not check format. Any format→rating mapping is a design choice to be validated with A/B data.
- Rowland 2014 vs Adesope 2017 disagree on MC vs short-answer; the classroom-inclusive meta-analysis (Adesope) favors MC, so "free response always better" is not safe for course-material transfer. Treat format-match to the course's exam format as a real moderator.
- Teach-back (Feynman-style explanation) has no meta-analytic effect size found in this session; the closest evidence is self-explanation rated "moderate utility" by Dunlosky et al. 2013.

## Key Question 3: Size of the testing effect and spacing effect (Roediger & Karpicke 2006; Cepeda 2006/2008 optimal gap; Dunlosky et al. 2013)

### Takeaway
Testing beats restudy by roughly 14 percentage points at 1 week in the canonical prose study (56% vs 42%, d = 0.83), with meta-analytic effect sizes of g ≈ 0.50–0.61 in the lab and g ≈ 0.50 in classrooms; spacing beats massing by ~10 points averaged over all delays (47.3% vs 36.7%), with the optimal gap being ~10–20% of the retention interval for delays of weeks and ~5–10% for a year. Dunlosky et al. rate exactly these two — practice testing and distributed practice — as the only "high utility" techniques.

### Cited Findings

**Testing effect**
- Roediger & Karpicke 2006, Exp. 1 (120 undergrads, TOEFL prose passages, ~30 idea units each) **[lab, prose/concepts]**: 5-min final test, restudy 81% vs test 75% (d = 0.52, restudy wins); 2 days, test 68% vs restudy 54% (d = 0.95); 1 week, test 56% vs restudy 42% (d = 0.83). — [Roediger & Karpicke 2006 PDF](https://colinallen.dnsalias.org/Readings/2006_Roediger_Karpicke_PsychSci.pdf)
- Exp. 2 (180 undergrads; SSSS vs SSST vs STTT, no feedback): at 5 min, SSSS 83% > SSST 78% > STTT 71%; at 1 week, STTT 61% > SSST 56% > SSSS 40%. Predicted-remembering ratings (1–7) were highest for the group that forgot the most: SSSS 4.8, SSST 4.2, STTT 4.0. — [Roediger & Karpicke 2006 PDF](https://colinallen.dnsalias.org/Readings/2006_Roediger_Karpicke_PsychSci.pdf)
- Meta-analyses: Rowland 2014 (lab) and Adesope et al. 2017 (lab + applied) — mean testing effect d/g ≈ 0.50–0.61. — [Frontiers 2018 review](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2018.02412/full)
- Classroom: Yang et al. 2021, 222 studies, g = 0.499 (with feedback 0.537). **[classroom]** — [Yang et al. 2021, PubMed](https://pubmed.ncbi.nlm.nih.gov/33683913/)
- Karpicke & Blunt 2011: retrieval practice > concept mapping on science texts, one-week delay, including inference questions. **[lab, prose/concepts]** — [Science](https://www.science.org/doi/10.1126/science.1199327)

**Spacing effect**
- Cepeda et al. 2006 meta-analysis (verbal recall; 839 assessments, 317 experiments, 184 articles; 254 spaced-vs-massed comparisons, 14,811 participants) **[mostly lab, word lists/pairs]**: spaced 47.3% vs massed 36.7% correct across all retention intervals (t(540) = 6.6, p < .001). By retention interval (massed → spaced): 1–59 s 41.2 → 50.1; 1–10 min 33.8 → 44.8; 10 min–1 day 40.6 → 47.9; 1 day 32.9 → 43.0; 2–7 days 31.1 → 45.4; 8–30 days 32.8 → 62.2; ≥31 days 17.0 → 39.0 (1 study). "The ISI producing maximal retention increased as retention interval increased." — [Cepeda et al. 2006 PDF](https://augmentingcognition.com/assets/Cepeda2006.pdf)
- Cepeda et al. 2008 (1,350+ participants, trivia facts, gaps up to 3.5 months, final delay up to 1 year) **[lab/online, facts]**: for any retention interval, performance first rises then falls as gap increases; optimal gap ≈ 20–40% of a 1-week test delay, ≈ 5–10% of a 1-year delay ("about 20% of the test delay for delays of a few weeks, falling to about 5% when delay was one year"). — [Cepeda et al. 2008, Psychological Science](https://journals.sagepub.com/doi/10.1111/j.1467-9280.2008.02209.x), [ERIC full text](https://files.eric.ed.gov/fulltext/ED505660.pdf)
- Spaced *retrieval* vs massed retrieval (Latimier et al. 2021, 29 studies): g = 0.74; expanding vs uniform schedules examined (see Gaps for the direction). — [Latimier et al. 2021, ERIC](https://eric.ed.gov/?id=EJ1310148)
- Dunlosky, Rawson, Marsh, Nathan & Willingham 2013 (PSPI): of 10 techniques, **practice testing** and **distributed practice** rated *high utility* (effective across ages, materials, and criterion tests); elaborative interrogation, self-explanation, interleaved practice rated *moderate* (promising but under-evaluated in education); summarization, highlighting, keyword mnemonic, imagery, rereading rated *low*. — [Dunlosky et al. 2013](https://journals.sagepub.com/doi/abs/10.1177/1529100612453266), [APS summary](https://www.psychologicalscience.org/news/releases/which-study-strategies-make-the-grade.html)
- Motivating forgetting numbers for a semester course: medical students forget "roughly 25% to 35% of basic science knowledge after 1 year, more than 50% by the next year" (Custers 2010, quoted in Lindsey et al. 2014). — [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)

### Inferences
- The testing effect *reverses* at 5-minute delays (restudy wins), so immediate re-quizzing inside the same session is not where the value lies; the value appears at ≥2 days. A tutor should therefore not count same-session re-checks as strong evidence of durable learning (FSRS-6's separate same-day update `w17..w19` reflects the same fact).
- Cepeda 2008's ratio rule gives a first-principles sanity bound for a semester: for material that must survive to a final exam ~12 weeks out, the first review gap should be on the order of 1–2.5 weeks (10–20% of 84 days), not 1 day; for a midterm 3 weeks out, ~4–6 days. FSRS with r = 0.9 will produce shorter early intervals than this; that is fine for *first* consolidation but the scheduler should let intervals expand fast toward the ratio bound.
- Students' metacognition is inverted (SSSS group most confident, lowest recall) — the UI must not let self-reported confidence override the scheduler.
- Transfer: the testing-effect evidence includes prose and classroom material (R&K 2006, K&B 2011, Yang 2021) and does transfer; the spacing meta-analysis (Cepeda 2006) is dominated by word-list lab work, but Cepeda 2008 (facts) and Lindsey 2014 / Rawson 2013 (course content, below) show the direction and rough magnitude hold for conceptual material.

### Gaps
- Latimier 2021's finding on expanding vs uniform spacing was not retrieved in detail (search snippet only reports the spaced-vs-massed g = 0.74); the older literature (Karpicke & Roediger 2007; Logan & Balota 2008) is mixed on expanding schedules, so do not assume expanding schedules add benefit beyond what a retrievability-driven model already produces.
- Cepeda 2006's optimal-ISI-by-RI table (the "1 day ISI best for RI < X" values) lies in pages not extracted here; only the abstract-level statement and Table 1 are cited.

## Key Question 4: Mixing reviews with new material (interleaving; Rohrer & Taylor) — when it helps and when it hurts

### Takeaway
Interleaving different problem/concept types produces large gains on delayed tests of *discrimination* (which method/concept applies) — d = 1.34 in Rohrer & Taylor 2007, g ≈ 0.42 meta-analytically — at the cost of worse performance during practice; it helps most for confusable categories and math/problem-type selection, and is weakest or absent for expository text and unrelated vocabulary. It is rated only "moderate utility" by Dunlosky et al. 2013 because classroom evidence was thin in 2013.

### Cited Findings
- Rohrer & Taylor 2007 (college students, volumes of four obscure solids): interleaved group worse *during* practice; on the 1-week test interleaved 63% vs blocked 20%, d = 1.34. **[lab, math procedures]** — [Rohrer & Taylor 2007 PDF](http://uweb.cas.usf.edu/~drohrer/pdfs/Rohrer&Taylor2007IS.pdf), [Rohrer 2012 review](https://files.eric.ed.gov/fulltext/ED536926.pdf)
- Taylor & Rohrer 2010 (4th graders, prism problems): interleaving improved the test-day ability to *choose* the correct procedure; the benefit is largely a discrimination benefit. **[classroom-adjacent]** — [Taylor & Rohrer 2010 PDF](http://uweb.cas.usf.edu/~drohrer/pdfs/Taylor&Rohrer2010ACP.pdf)
- Rohrer, Dedrick & Stershic 2015 (126 seventh graders, cluster-randomized, same problems interleaved vs blocked, tests 1 and 30 days later): interleaving improved mathematics learning; WWC "meets standards without reservations". **[classroom]** — [Rohrer et al. 2015 PDF](http://uweb.cas.usf.edu/~drohrer/pdfs/Rohrer_et_al_2015JEdPsych.pdf), [WWC](https://ies.ed.gov/ncee/wwc/Study/89950)
- Brunmair & Richter 2019 meta-analysis (59 studies, 238 effect sizes, 158 samples): interleaved vs blocked g = 0.42 [0.34, 0.50]; "interleaving can effectively foster inductive learning but ... the setting and the type of learning material must be considered, especially for expository texts and words" — the effect is driven by *similarity* between interleaved categories (high-similarity, confusable material benefits most; unrelated words/texts show little or negative effect). **[meta, mixed lab/classroom]** — [Brunmair & Richter 2019 PDF](https://www.psychologie.uni-wuerzburg.de/fileadmin/06020400/2019/Brunmair_Richter_in_press__2019_META-ANALYSIS_OF_INTERLEAVED_LEARNING.pdf), [Semantic Scholar](https://www.semanticscholar.org/paper/bb5392e8eaf53a38cc0d147f301cce74cecb4436)
- Firth et al. 2021 systematic review: interleaving as a concept-learning strategy is supported mainly for inductive category learning; evidence in expository/text learning is limited. — [Firth 2021, Review of Education](https://bera-journals.onlinelibrary.wiley.com/doi/10.1002/rev3.3266)
- Dunlosky et al. 2013 rated interleaved practice *moderate* utility: "the benefits of interleaving have just begun to be systematically explored". — [APS summary](https://www.psychologicalscience.org/news/releases/which-study-strategies-make-the-grade.html)
- Interleaving *is* spacing in disguise: Rohrer notes interleaved practice inherently spaces each problem type, which confounds the two; the discrimination benefit is what survives once spacing is controlled. — [Rohrer 2012 review](https://files.eric.ed.gov/fulltext/ED536926.pdf)

### Inferences
- In a session, mix due reviews from *sibling* concepts (same parent in the knowledge graph, high similarity — e.g., L1 vs L2 regularization, or the four integration techniques) and require the student to identify *which* concept applies before applying it. That is the interleaving payoff; mixing unrelated chapters gets only the spacing benefit and adds switch cost.
- Do not interleave during first acquisition of a concept if the student has no schema yet (the blocked group's practice advantage is real, and CLT below says novices have ~2–3 interacting elements of headroom). Introduce new concepts in short blocked bursts, then move them into the interleaved review pool at their first FSRS review.
- Expect learners to rate interleaved sessions as harder and less effective (Bjork's desirable-difficulty pattern; Rohrer's practice-phase deficit). Surface the delayed-test evidence in the UI rather than session accuracy.

### Gaps
- Effect sizes for interleaving *conceptual, non-mathematical* college content (e.g., history, biology definitions) were not located; Brunmair & Richter flag this as the weak zone.
- No study found that specifies an optimal ratio of new-to-review items within a session; the "1/3 review budget" style numbers come from the Lindsey/COLT design (new-chapter proficiency phase then a review phase), not from an optimization.

## Key Question 5: Successive relearning, and combining spaced retrieval with a knowledge-tracing estimate (Duolingo HLR, Lindsey et al. 2014)

### Takeaway
Successive relearning (retrieve-to-criterion, then relearn to 1 correct recall in ≥3 spaced sessions) raises course-exam performance ~10 points and 24-day retention from <20% to >60% in real college courses, with the prescriptive recipe "3 correct recalls initially, then relearn 3 times at widely spaced intervals" and a rapidly falling time cost (30–40 min → ~15 min → <5 min per relearning session for 8–10 definitions). Personalized, model-driven review (DASH + threshold selection) in a semester-long course beat massed review by 16.5 points (d = 1.42) and generic spacing by 10.0 points (d = 0.88) on a delayed cumulative exam, using ~30 min/week of review.

### Cited Findings

**Successive relearning [classroom + lab, conceptual definitions]**
- Definition: retrieval practice with corrective feedback until a criterion is met in session 1, then repeated relearning-to-criterion in later, spaced sessions; the "what" (retrieval) plus the "when" (spacing). — [Rawson & Dunlosky 2022, Current Directions](https://journals.sagepub.com/doi/full/10.1177/09637214221100484), [UNH guide (Dunlosky, Greve, Badali, Wissman & Rawson)](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-successive-relearning-dunlosky-greve-badali-wissman-rawson.pdf)
- Rawson & Dunlosky 2011 (JEP: General; items practiced to 1–4 correct recalls initially, then to 1 correct recall in 1–5 relearning sessions; retention tested 1–4 months later): prescriptive conclusion — "practice recalling concepts to an initial criterion of 3 correct recalls and then to relearn them 3 times at widely spaced intervals." — [Rawson & Dunlosky 2011, ERIC](https://eric.ed.gov/?id=EJ934616)
- Rawson, Dunlosky & Sciartelli 2013 (introductory psychology course, definitions of course concepts, ≥3 sessions ≥1 day apart): successive relearning boosted in-class exam performance by >10 points over baseline; exam questions were application (near-transfer), not definition recall; on a recall test 24 days after the exam students recalled >60% of successively relearned concepts vs <20% of self-studied ones; time-matched spaced *restudy* helped less than retrieval, and self-regulated practice helped less than the prescribed schedule. — [UNH guide](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-successive-relearning-dunlosky-greve-badali-wissman-rawson.pdf), [Rawson et al. 2013 listing](https://www.researchgate.net/publication/258845409_The_Power_of_Successive_Relearning_Improving_Performance_on_Course_Exams_and_Long-Term_Retention)
- Janes, Dunlosky, Rawson & Jasnow 2020 (biopsychology, high-stakes exam): "about a 10% boost" in exam performance. — [Janes et al. 2020, Applied Cognitive Psychology](https://onlinelibrary.wiley.com/doi/abs/10.1002/acp.3699)
- Higham et al. 2022 (time-matched, tests at ~42 and 68 days): significant benefit at 42 days and a smaller but still significant benefit at 68 days. — [UNH guide](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-successive-relearning-dunlosky-greve-badali-wissman-rawson.pdf)
- Problem-solving transfer: for math-style problem types, three separate to-criterion sessions vs one session with a 3-correct criterion gave a significant but small advantage on novel problems one week later (d = 0.28; performance ≈ 50%). — [UNH guide](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-successive-relearning-dunlosky-greve-badali-wissman-rawson.pdf)
- Time cost: "30 to 40 minutes to initially learn to correctly recall eight to ten lengthy definitions, but during the first relearning session, they may need only about 15 minutes, and the next session will likely take fewer than 5 minutes"; in a separate experiment ~3 min per concept to reach 1 correct recall initially, ~1 min per concept by the third relearning session; students who completed three relearning sessions recalled "nearly 60%" a month later. — [UNH guide](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-successive-relearning-dunlosky-greve-badali-wissman-rawson.pdf)
- Scheduling advice from the authors: with exams ~4 weeks apart, fit "perhaps three" extra relearning sessions per unit; before a cumulative final, one or two booster sessions on old material, which will be fast because relearning is rapid even for forgotten items; a concrete example schedule is "three extra sessions separated by 2 days." — [UNH guide](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-successive-relearning-dunlosky-greve-badali-wissman-rawson.pdf)
- Affective side effects (Rawson & Dunlosky 2022): students using successive relearning across a semester reported less anxiety, better attentional control, more sense of mastery, and more accurate metacognition than restudy controls. — [Rawson & Dunlosky 2022](https://journals.sagepub.com/doi/full/10.1177/09637214221100484)

**Personalized review with a knowledge-tracing model (Lindsey, Shroyer, Pashler & Mozer 2014) [classroom]**
- Setting: 179 eighth-grade third-semester Spanish students, 10 chapters introduced ~weekly, semester-long; retrieval-practice software (COLT) with typed translations and corrective feedback; each session = study-to-proficiency on the current chapter, then a review phase; review lasted "roughly 30 min a week," "only about 10% of the time students were engaged with the course." — [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)
- Design: one third of each chapter's items randomly assigned to each of three schedulers — massed (least-recently-studied item from the *current* chapter), generic spaced (least-recently-studied item from the *previous* chapter, a fixed ~1-week spacing), personalized (DASH prediction + closest-to-threshold policy). Trials were equated (≈7.6 proficiency + ≈8.0 review trials per item); mean days between review trials 0.12 / 1.69 / 4.70. — [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)
- Results: end-of-semester cumulative exam, personalized +12.4 points vs massed (d = 1.38) and +8.3 vs generic (d = 1.05); 28-day-delayed exam, +16.5 vs massed (d = 1.42) and +10.0 vs generic (d = 0.88); forgetting over the break 18.1% / 17.1% / 15.7%. Benefits concentrated on early-semester chapters. Only 22.3% (generic) and 13.5% (massed) of students scored better in those conditions than in their personalized condition. — [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)
- DASH beat baseline logistic models and performed on par with DASH[ACT-R] and DASH[MCM] variants at predicting held-out trials. — [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)

**Duolingo HLR [production app data]** — see Q1 for equations and Table 2 metrics; the live effect was +9.5% practice-session retention and +12% overall activity when HLR replaced the Leitner-based strength meters. — [Duolingo blog](https://blog.duolingo.com/how-we-learn-how-you-learn/)

### Inferences
- Successive relearning is the closest published protocol to "review loop for concepts in a college course" and it transfers to application questions. Encode it as a state machine per concept: `acquiring` (retrieve with feedback until 3 correct recalls, possibly across 2 sessions) → `relearn_1..3` (each: retrieve until 1 correct; spaced by the FSRS interval, floor 1–2 days) → `maintained` (FSRS long intervals; booster before cumulative exams).
- Budget guidance the evidence supports: ~30 min/week of review changed a semester outcome by d ≈ 1.4 (Lindsey); a relearning session for ~10 concepts is ~15 min the first time and <5 min by the third. So a daily review budget of 10–15 min (≈10–20 concept checks at 30–60 s each) is consistent with the classroom data; there is no primary-source number for a "maximum sustainable reviews/day" beyond Anki folklore (see Gaps).
- Combining KT + spacing: the winning classroom design used a *probability-of-recall* model over all prior attempts (DASH) and a *threshold* selector, not a fixed schedule. For Sapling: FSRS state per (student, concept) supplies R(t); a DASH/DAS3H-style logistic over windowed counts is the natural fallback for cold-start concepts with no FSRS state and for multi-concept items.
- Personalization matters more late in the semester and for early chapters — schedule the review budget to protect old material (the generic-spaced scheduler, which only ever reviewed the previous chapter, lost 10 points to personalization on the delayed exam).

### Gaps
- No peer-reviewed number for "how many reviews per day is sustainable"; the practical figures above are session-time observations from Rawson/Dunlosky classroom work and Lindsey's 30 min/week, plus the FSRS workload/knowledge simulation (which returns a retention, not a review count).
- The Lindsey et al. supplemental material (exact number of items per chapter, exam length, session length) was not retrieved; only the main paper's figures are cited.
- Successive-relearning studies used definitions and problem types with a human-graded or exact-match criterion; whether an LLM-graded "explain the concept" retrieval reproduces the same stability gain is untested in the literature found.

## Key Question 6: Cognitive-load limits on a session (Sweller; how many new concepts per session)

### Takeaway
Cognitive load theory's operative limit is not "N concepts" but "N *novel interacting elements* in working memory at once" — on the order of two to three for novices — so the number of new concepts a session can introduce depends on their element interactivity and the learner's prior schemas; the actionable rules are to reduce extraneous load, sequence low-interactivity elements first, and treat the desirable-difficulty techniques (spacing, interleaving, testing) as things to apply *after* a schema exists.

### Cited Findings
- Working memory "can handle only a very limited number—possibly no more than two or three—of novel interacting elements"; an element is "a concept or procedure that needs to be learned"; intrinsic load depends on element interactivity and prior knowledge (schemas chunk many elements into one); extraneous load comes from presentation and can be changed by instruction; germane load is the effort of building schemas into long-term memory. — [Cognitive Load Theory, EdTech Books encyclopedia](https://edtechbooks.org/encyclopedia/cognitive_load_theory), [Sweller, van Merriënboer & Paas 2019, Educ Psychol Rev](https://link.springer.com/article/10.1007/s10648-019-09465-5)
- Desirable difficulties (Bjork) and CLT are in tension: difficulties that are desirable for learners with adequate prior knowledge can overload novices; a 2025 comparative analysis frames difficulty as beneficial only when it does not exceed available working-memory capacity. — [Does difficulty moderate learning? (PMC 2025)](https://pmc.ncbi.nlm.nih.gov/articles/PMC12432286/)
- Bjork's desirable-difficulty framework: conditions that slow acquisition (spacing, interleaving, testing, generation) can enhance long-term retention and transfer; Lindsey et al. cite Bjork (1994) for "material should be restudied as it is on the verge of being forgotten." — [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf), [Desirable difficulties, after Bjork (notes)](https://notes.andymatuschak.org/zYB7kwEFRu8QALcbzbcoy9T)
- Retrieval-practice-based interleaving supports science learning only when the initial retrieval succeeds; failed effortful retrieval without feedback does not help (retrieval-effort literature, Pyc & Rawson 2009). — [Pyc & Rawson 2009](https://www.sciencedirect.com/science/article/abs/pii/S0749596X09000138)
- Empirical session sizes actually used in the classroom evidence: 8–10 lengthy definitions per successive-relearning set (30–40 min initial); ~7.6 study-to-proficiency trials per item in COLT; review ≈ 30 min/week. — [UNH guide](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-successive-relearning-dunlosky-greve-badali-wissman-rawson.pdf), [Lindsey et al. 2014 PDF](https://library.scottbarrykaufman.com/uploads/2014/01/Lindsey-et-al.-2014.pdf)

### Inferences
- Use the knowledge graph's edge structure as the element-interactivity estimate: a new concept whose prerequisites are all in `maintained` state has low effective interactivity (its elements are chunked); one with unmastered prerequisites is high-interactivity and should either be deferred or introduced with a worked example rather than a retrieval check.
- Practical cap per session: introduce at most ~3–5 new concepts when they are largely independent, fewer (1–2) when they are tightly coupled, and cap the total of (new + due reviews) by time (10–20 min) rather than by count; let the FSRS due list overflow into tomorrow rather than exceeding the budget.
- Order within a session: due reviews of *stable* concepts first (low load, warms retrieval), then new material (high load), then interleaved retrieval on the new concept's siblings only after the new schema exists (Rohrer's practice-phase deficit + CLT novice caveat).
- The tutor's chat should keep extraneous load down during acquisition (one representation, no competing tasks) and reserve generation/teach-back prompts for the review phase.

### Gaps
- No primary Sweller source gives a number of "new concepts per session"; the 2–3 novel-interacting-elements figure is the closest published limit and it is about simultaneous elements in working memory, not concepts per hour. Cowan's 4±1 chunk estimate was not retrieved in this session.
- No study located that manipulates the *number of new concepts introduced per tutoring session* and measures retention; the caps above are inferences.

## Cross-cutting notes for the report writer

- **What transfers from lab to classroom**: testing effect (prose → classroom quizzing g ≈ 0.50), spacing (word lists → facts → semester courses with d > 1 for personalized review), successive relearning (definitions → application exam questions, +10 points), interleaving (math procedures d = 1.34 lab → 7th-grade classroom RCT; weak for expository text). What does *not* have classroom evidence: FSRS's specific parameterization (Anki self-graded flashcards only), format-specific stability multipliers, and any "reviews per day" ceiling.
- **Minimal implementable scheduler** consistent with all of the above: FSRS-6 state (D, S, R) per (student, concept) with desired retention r = 0.90 (0.85 when the CMRR simulation says so, 0.95 in exam week); interval `I = (S/factor)·(r^(-1/w20) - 1)`; ratings derived from check outcome × check format × pre-check R; DASH/DAS3H logistic over windowed counts for cold start and multi-concept items; selection = FSRS-due items ordered by |R - 0.33| when over budget; session cap by minutes; successive-relearning state machine (3 correct → 3 spaced relearns); interleave sibling concepts only after acquisition; corrective feedback on every check; never expose self-rated confidence as a scheduling input.
