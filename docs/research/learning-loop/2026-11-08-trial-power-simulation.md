# Within-student trial: power simulation (2026-11-08)

This report was generated by `python -m learning_trial power`, run from `backend/` with seed 20261108. For a given seed it is deterministic, whatever the number of workers; this run took 59 minutes (3,537 s) on 10 cores that other heavy jobs were also using. It simulates the design in the [preregistration draft](2026-11-08-within-student-trial-preregistration.md) and analyses every synthetic trial with that draft's primary analysis, `learning_trial.analysis.fit_primary`. `backend/learning_trial/simulate.py` documents the data-generating model.

The numbers are only as good as the assumptions the draft marks †. Regenerate this report after any change to the analysis or the assumptions, and again once pilot data have replaced the assumed variance components. `python -m learning_trial power --fast` is a few-second smoke run for CI.

## Power of the primary analysis

Two-sided α = 0.05; seed 20261108; synthetic trials: 1000 per cell at n = 60, 90, 120, 150, 200, 250, 300; 400 per cell at n = 400, 600, 800, 1200, 1600, 2400, 3200. Each trial is analyzed by `learning_trial.analysis.fit_primary` (logistic GEE, two-way student x concept cluster-robust covariance, t on min(clusters) - 1 df). The Monte Carlo SE of a power p over r trials is sqrt(p(1 - p) / r): ±0.013 at 0.8 and ±0.007 at 0.05 for r = 1000; ±0.020 at 0.8 for r = 400.
