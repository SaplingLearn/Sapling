### G. Quiz results: two measures on one screen (needs a product decision) — OPEN

With `quiz_results_routing` on, the results show the graph's **mastery** and the learner model's **skill meters** together:

- `frontend/src/components/quiz/results/QuizResults.tsx:240-242` — the line under the concept name, `40% → 55%` (`masteryLine`, `:98-106`; the tier names are dropped when the learning block is present, but the percent stays).
- `frontend/src/components/quiz/results/QuizResults.tsx:153` — `Your mastery didn't change this time: …` (and `:143`, `:145`, `:150`).
- `frontend/src/components/quiz/results/LearningBlock.tsx:113` — `Your skill meters`; `:124` — `No skill meter moved this time. Each question counts toward your meters once a day…`

A student can read "Your mastery didn't change" next to a skill meter that moved, or the reverse: they are different numbers. Options, for the owner:

1. With the learning block present, name the top line as the map's: `Map mastery 40% → 55%`, and keep the unchanged note.
2. With the learning block present, drop the unchanged note (the block's own line says when nothing moved) and keep the top line as is.
3. Leave it; the quiz home already states one measure per card (`homeView.ts::cardMeta`), and results could follow the same rule later.

This pass recommends option 2: the smallest change, and it removes the one contradiction a student can see.
