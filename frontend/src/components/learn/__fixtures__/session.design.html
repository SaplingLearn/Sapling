Wrap up

A hash table turns a key into a bucket number with a hash function. With eight buckets:

h(k) = k mod 8

So 10 and 18 both land in bucket 2. That's a collision. What should the table do with the second key?

Put it in the next empty bucket?

Yes, that's linear probing. It works, but colliding keys bunch into runs of full buckets, and every new key that hashes into a run has to walk past all of it.
