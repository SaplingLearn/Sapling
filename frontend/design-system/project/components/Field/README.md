# Field

`fieldClass` is the one text-field look for `<input>`, `<select>` and `<textarea>`. A real `Input` component is still to come.

```tsx
import { fieldClass } from "@/components/ui";
```

## States

- Default
- Disabled

Source: `frontend/src/components/ui/Field.tsx`. The preview is a static render of its Storybook stories, styled by `components/bundle.css`; build with the classes it shows.
